# Echo Memory v0.5.0 — 谁在说话

## 主题：说话人分离（感知层补全）

- **whisperX 外置引擎（可选）**：设置 → 本机 AI → 转写引擎可切换内嵌/whisperX。whisperX 自动区分说话人（说话人 1、说话人 2…），1 小时录音约几分钟出稿。需 `pip install whisperx` + HuggingFace Token（接受 pyannote 模型协议），Token 保存在 macOS 钥匙串。内嵌引擎保持默认，零依赖可用不受影响。
- **说话人重命名**：录音详情新增「说话人」面板，把"说话人 1"改成真实姓名（如"张三"），可同时将姓名加入词汇库提升后续识别；逐字稿行自动显示新名字。
- **行动项归属说话人**：分析逐字稿带说话人标注（[片段][说话人]），行动项与决策自动附 owner；行动仪表盘与记录详情显示归属人。
- **重新转写可选引擎**：增强重新转写对话框内可单次选择 whisperX。
- **技术债（Loop 配额）**：新增 vitest UI 冒烟测试——设置面板"打开即加载/切 tab 加载"两条用例，防止 v0.4.2 类"永远正在读取"回归；已纳入 G0 门禁。

## 验证

Rust 107 项（含 whisperX JSON 解析、说话人重命名）+ 前端 9 项 + UI 冒烟 2 项 + typecheck/build/fmt 全绿；真实语音 E2E（内嵌引擎全链路）通过。whisperX 路径因本机未安装 whisperx 以单元测试覆盖，待真实环境启用后纳入 E2E。

## 已知边界

- whisperX 说话人分离质量受录音清晰度与重叠发言影响；pyannote 模型首次使用需联网下载。
- 说话人重命名作用于该记录全部逐字稿版本。
