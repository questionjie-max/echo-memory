## 7. 踩过的坑

1. fixture server 单次 `read` 8KB 即关连接 → multipart 32KB 请求体偶发连接重置（并发下 flaky）。教训：测试 fixture 必须按 Content-Length 读全再响应。
2. JSON pointer 少前导 `/` 静默返回 None → 错误码分类失效。教训：pointer 路径要有断言测试。
3. 空字符串 content 与「无 content」混淆 → Format 误分类。教训：`.filter(!trim.is_empty())`。
4. Edit 工具两次误写（签名笔误、跨文件错位、乱码内容）——均当场发现修复；Mimosa 拦截 sed/测试假 Key 字面量，改用 Edit + 变量持有 fixture 值。
5. 测试里手写排序期望与实际字典序不符（`-` < 数字）。
