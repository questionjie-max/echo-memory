## 4. 踩过的坑（均已沉淀为测试或注释）

1. **jsdom/浏览器 input 吞换行**：词汇库批量导入最初用单行 input，多行粘贴被吞成一个词 → 必须 textarea（有测试锁定）
2. **mark() 双重扣暂停**：elapsed_for 已扣暂停，又减一次 paused_millis，暂停过的录音标记整体前移 → 净时长口径 + 3 项 Rust 单测
3. **系统声单录时标记按钮可点必败**：mark_recording 只服务麦克风会话 → !micActive 禁用 + UI 测试
4. **fixture server 提前 close 连接**：multipart 32KB 请求体未读完 → 客户端偶发连接重置（并发下 flaky）→ 按 Content-Length 读全再响应
5. **LLM 命令同步冻结 UI**：三个产物命令原为同步 → async + spawn_blocking
6. **python 写测试文件的 `\n` 转义**：heredoc 里 `\\n` 被解一层成真换行 → 后续改用 Edit 工具
