## 🔴 P0 · 当前流水线在真实长录音上回归（转写）

**现象**：凯旋北路（37min 电话录音）——库内 9-18 凌晨旧流水线的转写是 1538 段通顺中文；
今天用**当前流水线**重跑，large-v3-turbo 产出 467 段英文幻觉循环、ggml-small 产出 371 段
「(speaking in foreign language)」。合成基准（≤83s 干净音频）两种模型都正常（CER 1–6%）。

**归因**：模型不是主变量（双模型同崩）；回归在 9-18/9-19 的流水线重构
（分块/预处理/滚动 prompt 级联，具体待二分。历史好转写可能出自已删除的 CLI 引擎路径）。

**影响**：⚠️ 修复前对任何 >90s 录音点「重新转写」会把库内好转写替换成幻觉。

**建议修复方向**（按性价比排序）：
1. 退化输出检测（低成本高信号）：转写语言与设置语言不符、n-gram 重复率超阈值 → 判失败，
   **不覆盖**已有转写版本；
2. whisper.cpp 温度回退（temperature fallback）——当前解码无任何回退（`whisper.rs:166-169` 只有 beam 5）；
3. 滚动 prompt 级联审查：`commands.rs:1351` 把上一段已接受文本作为下一段 initial prompt，
   幻觉会传染后续分块；
4. 用 git 历史二分 9-18 前后的分块/预处理差异。

**状态**：遗留（P0，建议下一迭代第一位）。
