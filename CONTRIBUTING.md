# Contributing to Echo Memory

Thank you for helping improve Echo Memory.

## Before opening an issue

- Search existing issues first.
- Include macOS version, app version, local dependency state, and reproducible steps.
- Redact paths, logs, titles, audio, transcripts, API keys, payment data, and other personal or customer information.
- Do not upload real recordings or transcript excerpts to a public issue.

## Pull requests

- Keep changes focused and explain the user-visible behavior.
- Run the checks documented in the README before opening a pull request.
- Preserve the local-first boundary: do not introduce an unannounced network path for audio or transcripts.
- Do not add MCP writes, public listeners, or external-system writes without an explicitly approved product change.

## Security issues

Do not file vulnerabilities as public issues. Follow [SECURITY.md](SECURITY.md).
